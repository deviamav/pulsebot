Telegram task bridge

Anonymous workflow between clients and designers

All communication runs through the bot. Neither side sees the other’s username, ID or profile. Access is invite-only, with one-time codes that carry a role and an expiry.

Roles

Permissions are verified at the handler, service and repository layers.

ADMIN Operations

Bootstrapped from ADMIN_IDS on first /start.

  • Issue and revoke invite codes
  • Ban or unban users
  • Full task visibility and closing

CUSTOMER Requests

Creates and tracks design tasks.

  • Step-by-step task wizard
  • Attach briefs, PDF, ZIP, PSD
  • Anonymous comments and approvals

DESIGNER Delivery

Receives tasks and delivers results.

  • Accept and update task status
  • Upload deliverables
  • Deadline reminders: 24h, 2h, overdue

Invite flow

Without a valid code, users only see “access restricted”.

Admin issues a code

Pick a role and an expiry. A one-time code is generated.

User opens the bot

Sends /start and enters the invite code.

Role is assigned

The code is consumed and the matching role menu appears.

Work begins

Tasks, comments and files flow through the bot, anonymously.
